# Documentação do produto

Este diretório separa evidência, ideias, decisões e execução. A separação evita transformar sugestões pedagógicas em requisitos sem validação.

## Fluxo orientado por especificações

1. **Pesquisar:** registrar fontes curriculares e sínteses em `pesquisa/`.
2. **Propor:** guardar ideias de interação em `atividades/`, ainda sem compromisso de implementação.
3. **Especificar:** criar uma spec em `specs/` com público, objetivo, interação, estados e critérios de aceite.
4. **Planejar:** decompor a spec aprovada em entregas pequenas em `planejamento/`.
5. **Implementar e verificar:** escrever o laboratório, os testes e validar os critérios de aceite.

Use nomes como `5-ano-porcentagem.md` para facilitar a busca e permitir que pesquisa, atividade, spec e planejamento se relacionem pelo mesmo tema.
