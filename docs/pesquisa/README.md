# Pesquisa curricular

Guarde aqui uma síntese por ano e unidade temática. Para cada fonte, registre título, órgão responsável, URL, data de acesso, páginas e implicações para o produto. Priorize documentos oficiais (BNCC, Currículo em Movimento do DF e materiais institucionais).

Não copie atividades de terceiros sem verificar licença e atribuição. Diferencie claramente exigência curricular, interpretação da equipe e ideia de atividade.
